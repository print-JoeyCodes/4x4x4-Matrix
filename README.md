# 4x4x4 LED Matrix
For my fifth week of Half Life, I decided to build a 4x4x4 LED matrix. I had seen a youtuber make one and thought it would be cool. 
It is also the natural progression from my warm up project of a 2D matrix.

I started by researching how most of these are made and relized that shift registers need to be used.
I was worried at first because that sounds like a complicated thing, but it turns out to be really easy.
I learned that all a shift register does is take an input stream, and store the data to then be released in parelell.
This is usefull as it allows me to control 16 leds at once only using 1 IO pin from my microcontroller.

I next laid out the schematic for the matix, which includes 4 layers of 16 LEDs that are selected through a transistor.
This allows the LEDs to be common cathode without the microcontroller handling the current.

When the esp32-c3 goes to display a frame, it reads a string of binary out of a file, this way I can swap animations easily.
It then loads 16 bits into the shift registers and opens the transistor for that layer.
Then the shift register open and the LEDs either connect the circut and light, or don't and stay off.
